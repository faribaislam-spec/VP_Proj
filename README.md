# RunGirlRun

**RunGirlRun** is an Android-based women's safety application designed to provide users with emergency assistance, safety information, safer routes and location-based safety features.

## Presentation Video

**Project Presentation:** https://youtu.be/JgzYu5vtrKk

## Objectives

* Provide quick access to emergency assistance.
* Manage emergency contacts efficiently.
* Provide safety tips and awareness information.
* Help users identify safer routes.
* Provide location-based safety features and notifications.
* Offer a simple and user-friendly safety platform.

## Key Features

* **User Authentication & Profile**: Registration, login, password reset and profile management.
* **Emergency Contacts**:  Add, edit, delete and view up to 5 emergency contacts with input and duplicate validation.
* **SOS Assistance**: Emergency messaging and nearby-user SOS notifications.
* **Safety Tips**: Categorized safety tips with add, edit, delete and validation functionality.
* **Safety Routes**: Map-based route functionality using safety-weight factors calculated from safety reports.
* **Safety Reports**: Safety reporting with validation and integration with safety-route functionality.
* **Police Station Notifications**: Demonstration of nearby police-station notifications.
* **Hidden Camera Detection**: Safety-focused hidden-camera detection functionality.

## Implementation Overview

Firebase Authentication manages user accounts and password reset, while Firestore stores safety-tip data. SQLite is used for local emergency-contact storage. Map and location services support safety routes and location-based features. Safety-route evaluation considers safety-related information rather than distance alone.
